
# Razvan Apps

The personal engineering organization of [Razvan Mares](https://github.com/RazvanM4), .NET / Azure solutions architect in Bucharest, Romania. Everything here is designed, built, deployed and operated by one person, end to end: the apps, the infrastructure they run on, and the pipelines in between.

## What lives here

Every repository below is private; this profile repository is the org's only public one.

| Repository | What it is | Stack | Status |
|---|---|---|---|
| Infrastructure | GitOps for a production-grade two-site homelab: a 4-node Proxmox cluster (a Dell R740XD server plus mini PCs), a 4-node k3s cluster, 50+ containers, CI/CD with GitHub Actions on self-hosted runners, full security stack | Proxmox, k3s, Docker, Traefik, GitHub Actions | Active |
| RazvanMares | razvanmares.ro — personal site and blog, with automated cross-posting of new articles to LinkedIn, Facebook and X | Next.js / React, C# / .NET | Active |
| Balauron | Trading site — an AI fintech, non-custodial trading-intelligence cockpit for prediction markets, crypto and stocks | Next.js / React, C# / .NET | Active |
| OpsHub | Service hub + ops web console for the homelab's long-running Windows services | C# / .NET (WinUI, Blazor) | Active |
| OpenClaw-Config | Configuration, agent workspaces, custom skills and extensions for an OpenClaw multi-agent AI gateway | JavaScript, TypeScript | Active |
| PokerMaster | Poker study and analysis desktop application | C#, C++, Python | Active |
| poker-gto-solver | From-scratch poker GTO (game-theory-optimal) solver — a research and study tool | Python, C | Active |
| Tipy | Sports tipster platform proving tipster skill through verified timestamps, closing-line-value tracking and Bayesian scoring | Next.js / React, C# / .NET | Paused |
| ProgMaster | C# & .NET interview-preparation knowledge base | Node.js, Express, PostgreSQL | Disabled |
| OllamaManager | Ollama model management API for local LLM inference — superseded by OpsHub | C# / .NET | Superseded |
| TelefoaneOkService | TelefoaneOk project worker for services integration | C# / .NET (planned) | Design only, no code yet |

Android apps and a few other private experiments are not listed here.
